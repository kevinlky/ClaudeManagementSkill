# SEO Content Optimizer

## Keyword Research Workflow

### Step 1: Identify and Expand Seed Keywords

Gather seed keywords from: core product/service terms, brand-adjacent terms, problem-solving queries, and question-based queries (how/why/what).

Expand using Google Search Console query data, Google Suggest autocomplete, Answer the Public, competitor analysis, and industry forums.

### Step 2: Prioritize with Keyword Map

| Keyword | Search Volume | Difficulty | Intent | Relevance | Priority |
|---------|---------------|------------|--------|-----------|----------|
| project management software | 12,100 | High | Commercial | Very High | High |
| how to manage projects remotely | 450 | Low | Informational | High | High |
| agile software tools comparison | 720 | Medium | Commercial | High | Medium |

Classify intent (commercial, informational, navigational) to match content type: commercial intent maps to product/comparison pages, informational to guides/tutorials, navigational to docs/support.

## On-Page SEO Implementation

### Title Tags

- Template: `[Primary Keyword] | [Benefit/Unique Angle] | [Brand Name]`
- Bad: "Project Management Software"
- Good: "Project Management Software for Remote Teams | [Brand]"

### Meta Descriptions

- Template: `[What page covers] + [Key benefit] + [CTA]`
- Bad: "This page is about project management software features."
- Good: "Manage projects 40% faster with AI-powered planning tools. Free trial. See how 10K+ teams collaborate."

### Header Structure

```
# [Primary Keyword] + [Value Proposition]

## What Is [Keyword]?
## How to [Action] with [Keyword]
## Best Practices for [Keyword]

### [Specific sub-topic 1]
### [Specific sub-topic 2]
```

See `references/seo-checklists.md` for detailed on-page checklist including image optimization guidelines.

## Content Gap Analysis

Audit top 3-5 competitors for your target keyword. For each, record URL, title, word count, header count, and unique points covered.

Identify gaps:
- Topics competitors cover that you don't
- Areas where competitors go deeper
- Unique angles you can offer (original data, tools, frameworks)
- Questions competitors leave unanswered

See `references/seo-checklists.md` for the full competitive audit template and improvement plan framework.

## Internal Linking Strategy

Use the **Hub & Spoke model**: create a comprehensive pillar page linked to 3-5 detailed cluster pages. Each cluster links back to the pillar with descriptive anchor text.

Per page targets:
- 3-5 links with primary keyword anchors to key pages
- 2-3 links with long-tail keyword anchors to supporting content

See `references/seo-checklists.md` for anchor text patterns and linking examples.

## Validation Checkpoint

Before finalizing any SEO optimization, verify:

- [ ] Keyword density 1-2% for primary keyword
- [ ] All internal links resolve (no broken links)
- [ ] Meta description under 160 characters
- [ ] H1 contains primary keyword
- [ ] Primary keyword in title within first 60 characters
- [ ] At least 3 H2 subheadings with keyword variations
- [ ] Alt text on all images
- [ ] Content length 800+ words for competitive topics
- [ ] CTA included and prominent

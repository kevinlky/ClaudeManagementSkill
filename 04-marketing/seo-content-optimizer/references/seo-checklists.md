# SEO Reference Checklists

## On-Page SEO Checklist

### Page Title
- Length: 50-60 characters
- Primary keyword near the beginning
- Include brand name if space permits
- Template: `[Primary Keyword] | [Benefit/Unique Angle] | [Brand Name]`

### Meta Description
- Length: 155-160 characters
- Include primary keyword naturally
- Include compelling call-to-action
- Template: `[What page covers] + [Key benefit] + [CTA]`

### Headers
- One H1 per page containing primary keyword
- H2s for main sections with semantic keyword variations
- H3s for sub-topics within sections

### Image Optimization
- Descriptive, hyphenated file names (e.g., `project-management-dashboard.png`)
- Alt text: 8-15 words, describe content, include relevant keywords naturally

## Technical SEO Essentials

- [ ] Mobile-responsive design
- [ ] Page load speed < 3 seconds
- [ ] HTTPS enabled
- [ ] XML sitemap submitted
- [ ] Robots.txt configured
- [ ] Canonical tags on duplicate content
- [ ] Schema markup implemented
- [ ] 404 pages redirect to relevant content

### Gap Identification Checklist

- Topics covered by competitors but missing from our content
- Depth assessment: do competitors go deeper on specific topics?
- Unique angles we could offer (original research, tools, frameworks)
- User intent gaps: questions competitors don't answer

## Internal Linking Reference

### Anchor Text Patterns

**Primary keywords** (3-5 links per page):
```html
<a href="/service-page/">primary keyword phrase</a>
```

**Long-tail keywords** (2-3 links per page):
```html
<a href="/resource-page/">long-tail variation with context</a>
```

### Hub & Spoke Model Example

```
Pillar: "Complete Guide to Project Management"
├── Cluster: "Agile Methodologies"
├── Cluster: "Team Collaboration Tools"
├── Cluster: "Resource Planning"
└── Cluster: "Risk Management"

Each cluster links back to pillar with descriptive anchor text.
```
